
# Funda Form Builder

A prototype architecture for a form-grid generator.

## How to?

### 1. install Node.js
Checkout https://nodejs.org  
```
node -v
```

---

### 2. Test

```
npm start
```
or 

[Preview Online](https://xizon.github.io/funda-form-builder/build)
